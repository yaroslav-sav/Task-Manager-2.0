# Task-Manager-2.0

desktop-приложение на PyQt6 для создания задач.

## Возможности

- Ввод названия задачи (однострочное поле)
- Ввод описания задачи (многострочное поле)
- Выбор приоритета: Низкий / Средний / Высокий (QComboBox)
- Дополнительные настройки: чекбоксы `Важное` и `Отправить уведомление`.
- Кнопка **Создать задачу** — собирает данные из формы и выводит результат в окно.
  Сохраняет результаты в JSON для последующей загрузки их в окно пользователя.
- Кнопка **Очистить все задачи**: очищает форму и сбрасывает статус
- Кнопка **Удалить выбранную задачу**: из JSON удаляется выбранная задача.
- Программа показывает количество созданных задач.
- Реализовано удаление выбранной задачи с подтверждением через QMessageBox.
- Добавлен отдельный QDialog «О программе», с выводом описания и автора проекта.
- При запуске программы задачи, которые уже созданны читаются из JSON и выгружаются в окно пользователя.
- Валидация: нельзя создать задачу без названия
